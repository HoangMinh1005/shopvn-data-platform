# Profiling nguồn — công việc tiếp theo

Lưu báo cáo tổng hợp, không lưu raw customer PII hoặc dump nguồn vào Git.

Kết quả cần có: schema, row counts, uniqueness, null rates, accepted statuses, timestamp semantics, orphan keys, source reconciliation và các giới hạn inventory/refund/marketplace line identity.

Chưa có profiling thực tế. Dùng [readiness checklist](../architecture/implementation-readiness.md) để theo dõi.
