# Kế hoạch ban đầu

Áp dụng [kế hoạch triển khai MVP](../mvp-implementation-plan.md) cho thứ tự/phạm vi stage, [architecture baseline](../baseline-v1.md) cho kiến trúc và [business rules](../../business/business-rules-v1.md) cho nghiệp vụ. [Readiness checklist](../implementation-readiness.md) là các bước tiền triển khai, không phải lộ trình stage hiện hành.
